# IS218 Game

NeuroNet is a VitePress research notebook and plan for a practice game.

## Local development

Use Node.js 22 or later.

```sh
npm ci
npm run docs:dev
```

Use `npm run docs:build` to verify the production build and `npm run docs:preview` to inspect it locally. For subpath hosting, set `DOCS_BASE` with leading and trailing slashes at build time.
