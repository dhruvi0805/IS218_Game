# Research and decisions

## Showing activity status

**Observed source check, November 12, 2026.** W3C's Success Criterion and Examples sections describe conveying information with a cue in addition to color. One example pairs color with text and an icon. [W3C guidance on Use of Color](https://www.w3.org/WAI/WCAG22/Understanding/use-of-color.html)

**Interpretation.** Highlighting can draw attention to a node while its text explains what changed.

**Assumption.** Students can use “Completed” and “Ready” to decide what to do next without coaching.

**Decision.** Use identical status text in both layouts so the [experiment](./experiment.md) compares the presentation.
