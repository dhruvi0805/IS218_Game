# Progress interface experiment

**Status: Planned**

Compare a connected skill network with a labeled activity list. Use the same mock progress, labels, and actions in both. Change the presentation order across reviewers when possible.

1. Without explaining the layout, ask the reviewer which activity is already completed.
2. Ask them to point to where they would start the next available activity.
3. Record their first answer, wrong turns, and any prompts needed for each layout.
4. Ask what they thought the network's connecting lines meant.

Keep the network if it communicates both states without coaching. If the lines imply prerequisites or hide the next action, revise the network or choose the list and repeat the task.
