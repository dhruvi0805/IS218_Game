# Creative concept comparison

## Project Question

### Research Question

**How can interactive mini-games and visual progress systems encourage students to engage with learning across different skills and topics?**

NeuroNet explores this question through a game where the player navigates a visual brain-like network. Different nodes represent cognitive skills or learning areas. Selecting a node opens a mini-game focused on a particular skill, and completing activities contributes to the player's saved progress.

The goal is not to claim that the game physically changes or improves a player's brain. Instead, the project uses the brain/network metaphor to make learning progress visible and give players a reason to return to different activities.

---


## Creative Concept Comparison

## Concept A — NeuroNet

NeuroNet is an interactive learning game where the landing page is a visual brain/network. Different sections of the network lead to mini-games focused on skills such as memory, pattern recognition, language, and logic.

Players can also connect these skills to different learning topics. For example, a player could learn a science concept and then complete a memory or pattern-based activity using that material.

### Example game loop

```text
                 INTERACTIVE BRAIN
                        |
              Select a skill/topic
                        |
                        v
                   MINI-GAME
                        |
                 Complete challenge
                        |
                        v
                  Score/result
                        |
                        v
              Save progress + result
                        |
                        v
                 Return to brain
                        |
                 Network progresses
```

### Example mini-games

**Memory**
- Show a sequence of objects, symbols, or information.
- Hide the sequence.
- Player reconstructs it.
- Difficulty increases as the player succeeds.

**Pattern Recognition**
- Show numerical, visual, or symbolic patterns.
- Player identifies what comes next or finds the pattern.

**Language/Association**
- Give the player a concept and several related or unrelated words.
- Player identifies meaningful relationships.

**Logic**
- Present a rule, sequence, or puzzle.
- Player determines the missing piece or solution.

### Main creative feature

The mini-games are represented as a connected network instead of a normal list of activities. The player can see which skills they have explored and how their progress develops.

## Concept B — Chemistry Alchemy

Chemistry Alchemy is a discovery game where players combine chemicals to discover new chemicals or reactions.

Players would begin with a small set of known elements or compounds and experiment with combinations.

For example:

```text
Chemical A + Chemical B
          |
          v
      Reaction
          |
          v
    New substance
          |
          v
      Unlock clue
```

The game could use a visual laboratory interface with chemicals that can be dragged into containers and combined.

### Main creative feature

The game would encourage experimentation and discovery. Players would not necessarily be told every possible combination, so part of the gameplay would be figuring out relationships between chemicals.

### Challenge

The chemistry system would require a larger set of rules and carefully verified reactions. The project could also become much larger if every discovered chemical needs to connect to additional combinations.

---


## Selected Concept

## NeuroNet

I am selecting NeuroNet because it provides a stronger combination of creative interaction, visual design, and manageable programming scope.

The brain/network landing page gives the project a distinct identity rather than making it feel like a collection of unrelated mini-games. It also gives the saved progress a meaningful visual representation.

Chemistry Alchemy is still a strong concept, but it would require more chemistry content and reaction rules to make the discovery system feel complete. NeuroNet allows the project to focus on the interaction model, game architecture, saved player data, and visual progress system.

---


## Audience

### Primary Audience

High school and introductory college students who want a more interactive way to practice learning.

### User Need

Traditional studying can make learning feel like a list of disconnected tasks. NeuroNet experiments with making learning more interactive by allowing players to choose activities, receive immediate feedback, and see their progress visually.

### Why this audience?

Students are already familiar with short-form games and interactive interfaces. A system built around short mini-games can potentially make practicing small amounts of material feel more approachable than a large study session.

This is an assumption that will need to be tested with users.
